# DriveGram Quick Reference Guide
## 🚀 Everything You Need in 2 Minutes

---

## 🔑 Login
1. Enter phone number (with country code)
2. Enter verification code (`12345` for demo)
3. You're in! 🎉

---

## 📤 Upload Files
- **Method 1**: Click "Upload" → Drag files into window
- **Method 2**: Click "Upload" → "Choose Files" → Select files
- **Multiple files**: Select many at once
- **Large files**: Up to 2GB supported

---

## 📁 Manage Files
| Action | How to Do It |
|--------|--------------|
| **Download** | Hover over file → Click ⬇️ |
| **Delete** | Hover over file → Click 🗑️ |
| **View** | Click on any file to see details |
| **Search** | Click 🔍 → Type what you want |

---

## 📂 Folders
- **Create**: Click "New Folder" → Type name → Enter
- **Open**: Click on folder
- **Go Back**: Click "Back" button or "Home"

---

## 🎨 Interface
| Element | Location | Function |
|---------|----------|----------|
| **Search** 🔍 | Top-right | Find files |
| **Dark Mode** 🌙 | Top-right | Switch themes |
| **User Menu** 👤 | Top-right | Account info, logout |
| **Sidebar** | Left side | Navigation, folders |
| **Main Area** | Center | Your files |

---

## 💡 Pro Tips
- **Drag & Drop** is fastest for uploads
- **Use folders** to stay organized
- **Search** works for partial names
- **Dark mode** saves battery at night
- **Refresh** page if something seems stuck

---

## 🛠️ Troubleshooting
| Problem | Solution |
|---------|----------|
| **Can't login** | Use demo code `12345` |
| **Upload stuck** | Check internet, try smaller file |
| **Can't find file** | Use search, check folders |
| **Page slow** | Refresh browser, close other tabs |

---

## 📱 Mobile Tips
- Works great on phones and tablets
- Use WiFi for large uploads
- Rotate device for better viewing
- Save to home screen for quick access

---

## 🔒 Security
- Files stored in YOUR Telegram account
- Always logout on shared computers
- Enable 2FA in Telegram for extra security

---

## 🆘 Need Help?
1. **Refresh page** first
2. **Check internet connection**
3. **Try again in a few minutes**
4. **Contact administrator** if problem persists
